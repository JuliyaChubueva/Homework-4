# Теоретическая часть

## 1. Парсер, считающий хеши 10 000 файлов → процессы

Подсчёт хеша — CPU-bound задача, а из-за GIL потоки не дают выигрыша на вычислениях, поэтому только процессы (`ProcessPoolExecutor`) загрузят все ядра процессора.

## 2. Бот, который на каждый запрос обращается к 5 внешним API → async

Бот почти всё время ждёт ответа от сети (I/O-bound), поэтому через `asyncio` и `httpx.AsyncClient` можно отправить все 5 запросов одновременно и обслуживать много пользователей в одном потоке.

## 3. Скрипт, выгружающий 100 000 строк из БД пачками → async

Основное время уходит на ожидание ответа базы данных (I/O-bound), поэтому с асинхронным драйвером (например, `asyncpg`) можно запрашивать следующую пачку, пока обрабатывается предыдущая; если есть только синхронный драйвер — потоки.
